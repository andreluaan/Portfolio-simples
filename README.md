# Portfólio André Luan · prévia

Prévia do meu portfólio: sites publicados e identidades visuais, com os PDFs das marcas abrindo na própria página.

**Ver online:** https://andreluaan.github.io/portfolio-previa/

## Projetos

- **SI Advocacia**: site institucional e proposta de nova identidade visual
- **AeR Corretores de Imóveis**: identidade visual, manual e kit de Instagram
- **Adeylma Vieira**: identidade visual e cartões
- **Nanquim System**: meu design system
- **Mundo de papel**: prévia do portfólio completo, ilustrado em nanquim

## Estrutura

```
index.html   página única (HTML, CSS e JS sem dependências de build)
img/         retratos em nanquim e capas dos projetos
pdfs/        apresentações e manuais das identidades
```

O leitor de PDF usa o PDF.js carregado do cdnjs.
